# BOT [GTA5RP]

Это многофункциональный бот, предназначенный для автоматизации различных повторяющихся действий на серверах GTA5RP, работающих на платформе RAGE Multiplayer. Он оснащён современным, удобным интерфейсом и набором настраиваемых модулей для разных игровых профессий и активностей.

## Особенности

*   **⛓️ Деморган:** Автоматизирует мини-игры "Токарь" и "Швейка". Включает опциональный HUD для отслеживания прогресса и таймеров.
*   **⛏️ Стройка и шахта:** Автоматически выполняет мини-игру с нажатием клавиш на стройке и в шахте, распознавая подсказки на экране.
*   **⚓ Порт:** Управляет работой в порту, автоматизируя движение (Shift+W) и реагирование на мини-игру с погрузкой контейнеров.
*   **🐄 Ферма коров:** Автоматизирует мини-игру с коровами, распознавая подсказки «влево-вправо» и нажимая нужные клавиши.
*   **🏋️ Качалка:** Помогает с прокачкой силы, автоматически нажимая пробел при появлении визуального сигнала, а также управляет авто-питанием.
*   **🍜 Кулинария:** Автоматизирует процесс приготовления различных блюд, таких как салаты, смузи и рагу, кликая по нужным ингредиентам и инструментам.
*   **🕹️ Анти-AFK:** Предотвращает кик за бездействие, имитируя виртуальный джойстик. Также есть опциональная функция автоматического вращения колеса фортуны в казино.
*   **⚙️ Современный интерфейс и настройки:** Стильный, анимированный интерфейс с настраиваемыми звуками и автоматической проверкой обновлений.

## Начало работы

Чтобы запустить бот локально, выполните следующие простые шаги.

### Требования

Бот разработан для Windows. Для корректной работы функций распознавания изображений и цветов рекомендуется запускать игру в оконном или безрамочном оконном режиме. Отключение сторонних оверлеев (например, NVIDIA Game Filter) может улучшить точность распознавания.

### Установка

1.  Перейдите на страницу Releases этого репозитория.
2.  Скачайте последний .zip файл.
3.  Если вы скачали .zip файл, распакуйте его в новую папку.
4.  Установите драйвер
4.  Запустите исполняемый файл app.exe.
5.  Рекомендуется запускать бота с правами администратора, так как ему нужно отправлять ввод в другие приложения и считывать экран.

> **⚠️ Важно:** Использование данного ПО может противоречить правилам сервера. Используйте на свой страх и риск. Разработчик не несёт ответственности за блокировки аккаунта или другие санкции.

## Конфигурация

Все настройки, выполненные через интерфейс, сохраняются в файле settings.json в корневой папке бота. Файл можно редактировать вручную для продвинутой конфигурации, но обычно это не требуется, так как все опции доступны в приложении.

## Сборка из исходников

Если вы хотите собрать приложение из исходного кода, вам понадобятся Python и необходимые зависимости.

1.  Клонируйте репозиторий:
    ```sh
    git clone https://gitflic.ru/project/dornode/bot.git
    ```
2.  Установите необходимые Python-пакеты. Основные зависимости:
    *   `PyQt5`
    *   `pyautogui`
    *   `opencv-python`
    *   `mss`
    *   `pynput`
    *   `keyboard`
    *   `vgamepad`
    *   `pygetwindow`
    *   `Nuitka`

3.  Запустите скрипт компиляции compil.bat. Это создаст самостоятельный исполняемый файл в директории build_temp.
